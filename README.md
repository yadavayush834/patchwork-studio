# ✳ Patchwork Studio

**Make the internet feel handmade again.**

A studio in your browser for websites that feel alive. Pick a world, stitch in living scenes, characters with real jobs and little creatures that wander your pages, then download a site that works anywhere.
No account. No server. Nothing hosted. Everything you make stays on your computer until you take it.

## ✦ What's inside

### 🪡 [Make a site](docs/sections/site-maker.md)
A website builder that feels like making a poster. Say what you're making and pick a feeling, and **Quick start** sews you a whole site. Then drag anything anywhere, and Patchwork turns it into a real responsive grid. Phones lay themselves out in reading order. **Rearrange** gives any section a new layout and keeps your words. **Shuffle** restyles the whole site. Living scenes and little residents only Patchwork has can go behind any section. Download a folder that works anywhere.

## ✦ The engines

Patchwork doesn't use a game engine or a page builder. Each kind of piece runs on a small engine written for it.

| Engine | What it does | Powers |
|---|---|---|
| **[Diorama](docs/engines/diorama.md)** | Turns one painting and its depth map into a small 3D place: a parallax ray march, glow and bloom, god rays, fog, water, GPU particles at real depths, a pixel mode with an automatic palette, and a title plane. WebGL2, no dependencies. | Reading Room, Forge, Tea House, Onsen, Arcade, Sky Isle, Overnight, the title cards |
| **[Title cards](docs/engines/title-cards.md)** | Sets your headline as a film title *inside* the picture, with an opening credit, a push-in and letters that write themselves on. | Hayfield, Blue Room, Night Train |
| **[Pixel scenes](docs/engines/pixel-scenes.md)** | One fragment shader per place, rendered small and snapped to a 16-colour palette through an ordered dither. | 10 procedural Scenes |
| **[ASCII](docs/engines/ascii.md)** | A cell renderer that batches glyphs by colour, a light buffer with long-exposure streaks, a paint studio, and *living sites* that follow the visitor's clock. | ASCII backgrounds, exported sites |
| **[Particles](docs/engines/particles.md)** | Creatures made of light in three.js: a procedural skeleton carrying 5,200 particles, and a painting rebuilt as 48,000 points with a shader wing-beat. | Night Run, Nocturne |
| **[Motion runtime](docs/engines/motion.md)** | GSAP and ScrollTrigger choreography, three.js objects posed by scroll, and Diorama for the painted stories. | 25 Motion templates |
| **[Creature kit](docs/engines/creatures.md)** | Sprites from strings, one shared click-through stage, scroll and pointer sense, and screen-reader announcements. | Components, Spirits |

## ✦ Run it

```sh
npm ci
npm run dev        # http://127.0.0.1:5174, which also rebuilds every engine
```

<details>
<summary><b>All the scripts</b></summary>
<br>

| Script | |
|---|---|
| `npm run dev` | Build the engines and start Vite on port 5174. |
| `npm test` | The node test runner over `tests/*.test.ts`. |
| `npm run build` | Engines, a type-check, then a production build into `dist/`. |
| `npm run build:diorama` | `src/diorama/engine.ts` → `public/diorama/diorama.js` (+ copies for heroes and scenes). |
| `npm run build:particles` | three.js heroes → `public/heroes2/<id>/hero.js`. |
| `npm run build:motion` | The Motion runtime → `public/motion/engine.js`. |
| `npm run build:ascii` | ASCII scenes → `src/ascii/runtime.generated.js`. |
| `npm run build:heroes`, `build:mosslight` | The original heroes, and the Mosslight template's zip. |

</details>

<details>
<summary><b>Where things live</b></summary>

Before calling a change done: `npm test`, `npm run build`, and **look at it in a real browser**, with the GPU on for anything that moves. If you're an agent, read [AGENTS.md](AGENTS.md) first.

## ✦ What we care about

- **Local first.** Projects live in your browser. Downloads make no network requests.
- **Original.** Every painting, creature and scene was made for Patchwork. References are studied for *how* they work, never copied (see [docs/REFERENCES.md](docs/REFERENCES.md)).
- **Everyone gets in.** Real inputs under every playful control, keyboard paths, screen-reader text, and a still frame for anyone who asks for less motion.
- **It pauses.** Nothing animates offscreen or in a hidden tab.
