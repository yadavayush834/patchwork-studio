# Hero sections

Five original one-screen openings, separate from the page editor and scroll-led Motion Templates. Open **Hero sections** in the dashboard sidebar, or use `?collection=heroes`. Each scene has a customizer and an independent page at `?view=hero&hero=ID`.

| Hero | Composition | Live visual | Primary artwork action |
| --- | --- | --- | --- |
| Facet | Ice-gray canvas, Syne typography, a chrome form alongside the copy | Ray-marched, twisted metallic ribbon in GLSL | Reshape its cross-section |
| Undertow | Charcoal, warm characters and Instrument Serif | Thousands of depth-sorted glyphs form a rotating nautilus | Reverse and turn the shell |
| Daybreak | A centered pixel masthead over a miniature landscape | GLSL clouds, layered hills, trees and shimmering river | Transition between day and dusk |
| Lattice | Coral, Bricolage Grotesque and an asymmetric wire surface | A vertex-deformed WebGL mesh | Fold/unfold the surface |
| Frequency | Large Syne type inside a dark light chamber | A fluted, warped spectral light field | Move the light through the fins |

These are reusable concept scenes, with no invented customer proof or backend transactions. With an empty button link, the action changes the artwork. Set a real link and button label to connect the hero to a product or project.

## Customize and reuse

The customizer edits brand, headline, description, action text/target, accent, speed and art intensity. Values persist under `patchwork:hero:v1:ID`; project documents and IndexedDB are untouched. Desktop and phone previews use the same runtime as the independent website and downloaded component.

Download a ZIP to get a runnable `index.html`, reusable `hero.js`, local font assets, license notices, configuration JSON, and original editable TypeScript/CSS/shaders with a rebuild script. A static HTTP server is recommended. No CDN, API key, React app or Patchwork service is needed to run the compiled export.

```html
<script src="./hero.js" defer></script>
<patchwork-hero
  scene="undertow"
  brand="Your studio"
  headline="A different way to see."
  cta="View our work"
  href="https://example.com/work"
></patchwork-hero>
```

Keep `fonts.css`, `fonts/` and `licenses/` beside the script. The runtime loads the font stylesheet relative to its own script URL. The namespaced font families are global; all layout styles are isolated inside Shadow DOM. Change the element height to fit an existing layout, or keep its default `100svh`. Exposed CSS parts: `hero`, `header`, `headline`, `description`, `action`, `footer`. Multiple instances can coexist. Frameworks can use the custom tag with native event subscriptions through a DOM ref.

Attributes: `scene`, `brand` (28 characters), `headline` (80 characters, up to three explicit lines), `body` (180), `cta` (32), `href`, `accent` (six-digit hex), `speed` and `intensity` (0.25–1.8). `paused` and `reduced` are boolean attributes; remove them to disable. Native events: `hero-ready`, `hero-action`, `hero-motion`, `hero-renderer`. See the downloaded README for event payloads and source rebuild instructions.

## Runtime and accessibility

The artwork is decorative canvas content. Headlines, descriptions and actions are semantic HTML; controls work with a keyboard. Custom text is escaped and executable link schemes are rejected. Long copy is measured against the available screen height and display type shrinks to fit. Review your final copy and accent contrast.

Animations stop when the element is offscreen, the tab is hidden, the scene is paused, or reduced motion is requested. Reduced motion keeps a complete static composition and immediate artwork variations. Listeners, observers, GSAP timelines and WebGL resources are disposed when the element is removed. WebGL failure leaves readable text and working actions. Rendering resolution and update frequency are bounded for laptop use.

## Source and provenance

- Canonical source: `src/heroes`; runtime: `public/heroes/hero.js` generated by `npm run build:heroes` and normal dev/build commands.
- Original scene geometry, shader code, CSS and ASCII composition: Patchwork contributors, MIT in each export.
- GSAP is bundled for entrance choreography and retains its notice.
- Instrument Serif, Syne and Bricolage Grotesque were downloaded from the official `google/fonts` repository. DM Sans, Space Mono and Silkscreen reuse the project's local fonts. All six retain their SIL Open Font License files in `public/heroes/licenses` and exports.
- Gallery covers are screenshots of the actual renderers, not mockups or third-party images.

## Browser verification

After building, serve the production output on a separate QA origin. Run:

```sh
PATCHWORK_QA_URL=http://127.0.0.1:5193 \
PATCHWORK_CHROME=/path/to/chrome \
node scripts/verify-heroes.mjs
```

The test uses a fresh browser context, downloads and extracts all five ZIPs, rebuilds the shipped source, serves exports on an independent local origin, blocks external requests, and checks rendering, edits, persistence, keyboard actions, motion controls, one-screen layouts, multiple elements, cleanup and WebGL failure. It never clears the user's browser profile or IndexedDB.
